# ResiManager

Residence Management Application

## 🚀 Quick Start

```bash
flutter pub get
flutter run
```

## 📋 Requirements

- Flutter SDK
- Dart 3.0+
- Android Studio / Xcode

## 📁 Project Structure

```
├── assets/          # Images, fonts, data
├── ios/             # iOS configuration
├── lib/             # Source code
├── web/             # Web support
├── windows/         # Windows support
├── pubspec.yaml     # Dependencies
└── analysis_options.yaml
```
